# Knooppunt

Fietsknooppunten plannen en volgen. Tik op de nummers op de kaart, de app legt de route er langs het netwerk tussen, en tijdens het fietsen zie je groot welk knooppunt er nu aankomt.

- Download de nieuwste `Knooppunt.apk` via **Releases** en installeer hem.
- Kaart en knooppunten komen van OpenStreetMap. Bekeken gebieden blijven op je telefoon staan.
- Routes opslaan kan op de telefoon, en exporteren als GPX naar bijvoorbeeld je fietscomputer.
